# 指标口径（全站唯一）

核心指标在 `pipeline/build_marts.py` 中实现。前端展示聚合遵循本契约；静态月频直接消费导出的月表，离线包没有覆盖的明细明确报缺失。验证范围及限制见 `release_completion_report.md`。

## 样本

- 股票池：`SSE`/`SZSE` 的 主板 + 创业板 + 科创板；北交所默认排除。
- 有效样本：当日有行情行，close、adj_factor、adj_close 为正且有限，ret 有限且大于 -1。
- 剔除：按 list_date 和交易日历计算的上市前 5 个交易日。缺上市日期不得发布；n_hist_all 仅表示已加载有效观察数。
- 停牌：无行情行，不计入分母；不补造收益。
- ST 不因名称被排除。EW、CSD、IQR、q10/q90包含平盘，breadth仅在分母剔除平盘；均使用上述有效且非新股池。

## 收益

| 名称 | 公式 | 备注 |
|---|---|---|
| 日收益 | `pct_chg / 100` | 与 `close/pre_close-1` 交叉校验 |
| 复权收盘 | `close × adj_factor` | 用于 MA / 新高；市场区间收益为日 EW 复利 |
| 等权收益 | `mean(ret)` | 主口径 |
| 市值加权 | `Σ wᵢrᵢ`，`wᵢ = circ_mv_{t-1} / Σ circ_mv_{t-1}` | t-1 为上一市场交易日，当日有收益且前日正权重的股票内归一；缺前日行情退出加权，不沿用旧权重 |
| 中位数 | `median(ret)` | 抗极值 |

## 广度

- `breadth = N(ret>0) / (N(ret>0) + N(ret<0))`，平盘剔除。
- `ma20_breadth / ma60_breadth / ma250_breadth = N(adj_close > MA) / N(有足够历史)`：
  分母分别要求 `n_hist_all ≥ 20 / ≥ 60 / n_hist252 ≥ 250`，避免新股用不完整窗口的均线。

## 集中度

- `hhi = Σ wᵢ² × 10000`。
- `top10_share = Σ_{Top10权重} |wᵢrᵢ| / Σ|wᵢrᵢ|`（有界 0–1，避免分母接近 0 时爆表）。
- `top10_contrib_pct = Σ_{Top10权重} wᵢrᵢ × 100`（pp）。
- `gain_share_top5pct = 涨幅前 5% 股票的正收益之和 / 全部正收益之和`。
- 无有效权重时CW/HHI为空；全平盘时breadth和Top10波动占比为空，不补0。

## 分化

- `csd = stddev_samp(ret)`，存储为收益小数，显示 pp 时乘100。
- `iqr = q75 − q25`，存储为收益小数，显示 pp 时乘100。
- `ew_cw_gap = ew_ret − cw_ret`（大小盘/权重分化代理）。

## 轮动滚动指标（mart_sector_roll）

| 名称 | 公式 | 备注 |
|---|---|---|
| `ret_rN` | `exp(Σ ln(max(1+ew_ret, 1e-6))) - 1`，取该行业最近 N 条观测行 | N ∈ {5,10,20}。不足 N 行或窗口内有空收益时返回 null。单位为小数 |
| `br_rN` | 在同一组观测行上计算 `avg(breadth)` | 不足 N 行或窗口内有空广度时返回 null。单位为小数 |
| `rank_rN` | 当日按非空 `ret_rN` 降序排名 | 收益为空则名次为空；并列同名次并跳号，界面列出全部并列第一 |

**注意**：`ret_rN` 是**复利**累计，不是简单求和。展示层面另有"显示平滑"（指数平滑，半衰期可调），
平滑只作用于图形坐标，**排名与所有数字一律用本表原始值**。

每个行业按日期排序，窗口包含当前观测行。某个交易日缺整条行业行时，该日不占位置，窗口向前取样。例如中间缺一日时，10 条观测覆盖 11 个市场交易日。现有观测行的空字段仍占位置，并使相应指标为空。`ret_r20` 与 `mart_sector_rank.ret20` 使用相同的 20 条观测窗口。两个公式在 `1 + ew_ret ≥ 1e-6` 时相同，滚动表另外对复利因子设 `1e-6` 下限。缺整行日期没有气泡，轨迹仍断开。

> 展示用成交额（气泡面积）不复制进本表：`/api/sectors/roll` 与静态导出在查询时
> `LEFT JOIN mart_sector_day` 取 `amount`（单位：元，四舍五入到元后转 BIGINT）。缺行或金额不可用时以空心菱形表示未知。缺滚动表时导出保留 `sector_roll = null`，其余页面仍可使用。

> 运维：发布走 `pipeline.release`，完整重建时在 `mart_sector_day` 之后生成 `mart_sector_roll`。`build_marts --only sector_day` 同事务刷新滚动表。`--only sector_roll` 使用当前 `mart_sector_day`。

## 情绪

- 涨停：`close ≥ up_limit × 0.999`；跌停：`close ≤ down_limit × 1.001`（`stk_limit` 真实价）。**这是全站唯一的涨跌停口径，含 ST，全历史无缺失**，`mart_market_day.limit_up_n / limit_down_n` 由它汇总。
  - 与交易所官方名单（Tushare `limit_list_d`，**不含 ST**）的量化差异：含 ST 口径日均多 14.8 家（最大 262）；剔除 5% 涨跌幅后的 `limit_up_non5pct_n` 日均差 4.1 家（最大 224）。因此**与同花顺等外部软件对不上是预期行为**，不是数据错误。
- `limit_up_non5pct_n` / `limit_up_5pct_n` 按 `up_limit / pre_close - 1 ≥ 6%` 划分 10%/20% 与 5% 涨跌幅档，是**档位统计不是 ST 身份统计**；旧 `limit_up_ex_st_n` / `limit_up_st_n` 保留字段但恒为 NULL。
- **只有两项指标依赖官方名单 `limit_list_d`**：炸板率与封单额。该接口当前无权限，覆盖率不均（2016–2018 无、2019 仅 24 天、2020–2025 完整、2026 仅 90/216 天），因此：
  - `broken_rate = broken / (limit_up_list_n + broken)`，**官方名单为空时为空**；
  - **不使用日线近似值顶替**。日线只能算出"盘中触及涨停价但收盘未封住"的家数，其定义比官方"炸板"更宽（2024-10-08：日线 2038 家 vs 官方 631 家），顶替会让数值与交易所名单不可对账。
- 连板：按价格判定的连续市场交易日涨停数；停牌/缺行情日中断。首板=1、`streak_n` 为>=2；`max_streak` / `streak_n` / `first_board_n` **全部为价格口径、不依赖 `limit_list_d`**，派生表与 `feat_stock` 明细逐日自洽（审计项「连板/最高板与明细自洽」）。
  - 与官方 `limit_list_d.limit_times` **不对齐**：官方口径在 1,569 个可比日里，连板家数日均差 5.0 家（最大 90），最高板数日均差 2.0 板（最大 16）。这是定义差异（官方名单不含 ST、按其自身连板序列计算），不是错误；对外比较时需说明。
- 新高/新低：`adj_close ≥ 252 日最高` / `≤ 252 日最低`，需 ≥250 日历史。

## 状态分类

| 状态 | 条件 |
|---|---|
| 普涨 | `ew_ret > 0` 且 `breadth ≥ 0.50` |
| 集中上涨 | `ew_ret > 0` 且 `breadth < 0.50` |
| 结构分化 | `ew_ret ≤ 0` 且 `breadth ≥ 0.50` |
| 普跌 | `ew_ret ≤ 0` 且 `breadth < 0.50` |

阈值固定，不随图形调整；页面同时保留连续值，避免把四类当自然规律。

## 月度与持仓

月表 ew_ret/cw_ret 是日收益平均值，ew_ret_cum 才是每日EW复利。指数月累计缺任一日即空。
行业 ret20 需完整20条日观察。持仓池保留每股最后报价，quote_date 标记报价日；无当日行情时 is_stale=true、当日ret/amount按0标记，但前端据此将今日盈亏与组合日收益显示为未知，不当作平盘。is_suspended 为 null，因为缺报价不能证明停牌。今日盈亏=股数×(close−pre_close)，组合日收益=Σ今日盈亏/Σ期初市值；假设股数不变，不含交易和现金分红。
资金流仅汇总同一有效市场样本中有资金流记录的股票，缺记录不补0。
