## 5. 复现（现行命令，2026-11-27 起）

```powershell
$env:ASHARE_RADAR_LOAD_ENV = "0"
python -m pipeline.bootstrap        # 快照 -> core（一次性）
python -m pipeline.update_daily     # 增量
python -m pipeline.build_marts
python -m pipeline.export_static
```

> 注意：`python -m pipeline.refresh_meta` 在当前代码中无入口调用（审核 W3-13），不要写进标准流程；
> 新股/退市元数据由 `bootstrap_api._load_meta` 在抓取时加载。
> 历史部分日修复只在隔离副本运行：先 `set ASHARE_RADAR_DATA_DIR=<副本目录>` 再
> `python -m pipeline.repair_history --apply`（默认只生成计划）；生产库接管走
> `python -m pipeline.promote_repair --source <副本>/lake.duckdb`（v0.4.3）。
