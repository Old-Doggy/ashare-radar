# I08 · 轮动强度刻画行情性质

> **as-of：2026-11-26**（样本 2018-01-01..2026-11-26，共 2159 个交易日）｜数据源：`lake.duckdb` ｜生成命令：`python scripts/gen_insights.py --start 2018-01-01 --end 2026-11-26`
> 本文件已按 v0.4.3 接管后的库重算（192 个历史部分日已回补）；数据再次更新后用同一命令重跑即可，以重跑输出为准（口径见 [known_limitations.md](../known_limitations.md)）。

**问题**：行业排名迁移速度，能否区分单边行情与快速轮动？

**口径**：`rotation_intensity_t = mean_i |rank_{i,t} − rank_{i,t−1}|`，排名按 20 日累计收益。

**证据**：2018-01-01 以来轮动强度均值 **2.33 名/日**，95 分位 3.81；最高 6.77。

| trade_date | rotation |
|---|---|
| 2025-05-08 | 6.77 |
| 2019-11-25 | 6.65 |
| 2026-09-04 | 6.45 |


**图表位置**：Sectors 页轮动视图（行业强度云，v0.4.0 起；`#/labs?demo=rotation` 可单独查看）。

**边界**：排名基于 20 日窗口，窗口选择会改变强度绝对值；只做相对比较。
